verbatim legal code and nothing else, so that licence detection tools recognise
it. This file explains what the licence covers here, and what it does not.

The benchmark notebook `benchmark` in this repository -- the harness, the prompt
construction, the complexity tiering and the scoring code -- is covered.

you give appropriate credit, link to the licence, and indicate whether changes
were made.
